## Patterns and oddities
- Pane names at +0x0C (corrected offset), grp1 names at +8, mat1 names are 20 bytes. Texture names in txl1 are `<name>.tpl`; fonts `<name>.brfnt`.
- Animation layout: pai1 at 0x10; entry offset table at +0x10 (rel. section), texture-name offset table at +0x14 (rel. +0x14). Split variants (brlpa/brlvi/brlmc) share the pai1 layout and carry their own target names.
- Naming convention: many anims are `<layoutBase>_<animName>.brlan` (e.g. `systemWindow_00_in_00.brlan`); where a layout matches that name pattern it is preferred over the other layouts with the same panes.

- Moved shader effect anims in assets/shaders/effects/<scene>/ match the layouts of their original `.arc.d` by basename, so their target names still link to src/ layouts.
